# Agri Suraksha

Agri Suraksha is an AI-powered agricultural risk and safety platform designed to help farmers make better decisions using weather intelligence, crop insights, and risk management tools.

## Features

- Weather-based agricultural risk information
- Crop and farming insights
- Farmer-focused risk management
- Interactive dashboard
- Map-based visualization
- AI-assisted decision support

## Tech Stack

- Python
- Streamlit
- Pandas
- NumPy
- Folium
- Open-Meteo API
